# Login and Registration System

A simple C++ console application for registering users, logging in, and resetting passwords.

## Features

- Register with an email and password
- Log in with saved credentials
- Reset a password after verifying the current password

## Run the project

Compile the program:

```bash
g++ -std=c++11 main.cpp -o main
```

Then run it:

```bash
./main
```

User information is saved locally in `users_data.dat` while the program is running.
